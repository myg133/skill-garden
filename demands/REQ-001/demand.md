# REQ-001: Admin UI 多语言支持（中/英）

## 基本信息

| 属性 | 值 |
|------|------|
| **REQ 编号** | REQ-001 |
| **标题** | Admin UI 多语言支持 |
| **优先级** | P0 (优先) |
| **状态** | 草稿 |
| **创建日期** | 2024-08-30 |
| **负责人** | - |

## 需求描述

Admin UI 需要支持中文和英文两种语言，用户可以在界面上自由切换语言，切换后所有界面文字即时更新。

## 背景

当前 Admin UI 仅有英文界面，为支持中文用户，需要增加多语言功能。

## 技术方案

### 1. 技术选型

| 项目 | 选择 | 理由 |
|------|------|------|
| 框架 | svelte-i18n | 功能完整、社区活跃、支持懒加载 |
| 语言 | 中文 (zh) + 英文 (en) | 可扩展 |

### 2. 目录结构

```
src/
├── i18n/
│   ├── index.js          # 初始化 + 配置
│   ├── en.json            # 英文翻译
│   └── zh.json            # 中文翻译
```

### 3. 实现要点

- 语言文件按模块组织（common, auth, nav, skills, ...）
- 语言偏好存储在 localStorage
- 支持 URL 参数切换语言（?lang=zh）
- 语言切换器放在导航栏或用户菜单

### 4. 需要翻译的页面

| 模块 | 页面/组件 | 翻译量 |
|------|-----------|--------|
| 认证 | Login, Register | ~20 条 |
| 导航 | Nav, UserNav | ~15 条 |
| Skills | Skills, SkillDetail | ~50 条 |
| 组织 | Organizations, Groups | ~40 条 |
| 用户 | Identities, Profiles | ~30 条 |
| 工具 | OrgTools, ApiKeys | ~25 条 |
| 系统 | Tenants, Roles, AuditLogs | ~40 条 |
| 通用 | EmptyState, Badge, Loading | ~20 条 |
| **合计** | | **~240 条** |

## 验收标准

| ID | 验收项 | 验证方法 |
|----|--------|-----------|
| AC-001 | 页面加载时自动检测浏览器语言 | 浏览器语言设为中文，刷新页面默认显示中文 |
| AC-002 | 页面右上角有语言切换器 | 视觉检查 |
| AC-003 | 点击语言切换，中英文切换生效 | 点击切换，检查各页面文字 |
| AC-004 | 语言偏好保存在 localStorage | 刷新页面后语言保持 |
| AC-005 | URL 参数 ?lang=zh/?lang=en 强制指定语言 | 访问带参数 URL |
| AC-006 | 所有页面文字已翻译 | 逐页面检查无遗漏英文 |

## 依赖

- svelte-i18n

## 风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 硬编码文字遗漏 | 部分页面仍有英文 | 测试阶段逐页面检查 |
