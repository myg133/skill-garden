# REQ-001 验收标准

## 验收标准

### AC-001: 语言自动检测

**描述**: 页面加载时自动检测浏览器语言，优先显示对应语言

**验证方法**:
1. 设置浏览器语言为中文
2. 清除 localStorage
3. 访问 http://localhost:5174
4. 页面应默认显示中文

**通过标准**: 默认显示中文界面

---

### AC-002: 语言切换器存在

**描述**: 页面右上角或用户菜单中有语言切换按钮/下拉框

**验证方法**:
1. 登录后查看页面右上角
2. 应能看到语言切换选项（国旗图标或 "中/EN" 文字）

**通过标准**: 语言切换器可见

---

### AC-003: 切换生效

**描述**: 点击语言切换，中英文即时切换

**验证方法**:
1. 页面默认英文
2. 点击语言切换为中文
3. 刷新页面验证语言保持

**通过标准**: 所有页面文字随语言切换而变化

---

### AC-004: 语言偏好持久化

**描述**: 用户选择的语言保存在 localStorage，刷新后保持

**验证方法**:
1. 选择中文
2. 刷新页面
3. 仍然是中文

**通过标准**: localStorage 中有 `locale` 字段，刷新后语言不变

---

### AC-005: URL 参数强制语言

**描述**: URL 参数 ?lang=zh/?lang=en 可强制指定语言

**验证方法**:
1. 访问 http://localhost:5174/?lang=zh
2. 应强制显示中文
3. 访问 http://localhost:5174/?lang=en
4. 应强制显示英文

**通过标准**: URL 参数优先于 localStorage

---

### AC-006: 全页面翻译覆盖

**描述**: 所有 Admin UI 页面无遗漏英文

**验证方法**:
1. 切换到中文
2. 逐页面检查：
   - [ ] 登录/注册页
   - [ ] Dashboard/统计页
   - [ ] Skills 列表/详情
   - [ ] Organizations 列表/详情
   - [ ] Groups 列表/详情
   - [ ] Identities 用户管理
   - [ ] API Keys
   - [ ] Audit Logs
   - [ ] Settings 设置页
   - [ ] 系统管理 (Tenants, Roles, System Roles)

**通过标准**: 所有页面无遗漏的中文翻译

---
